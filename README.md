Python Fundamentals — Learning Exercises

A collection of coursework exercises from Intro to Python and early Data Science with Python coursework. These cover core language fundamentals rather than end-to-end analysis — kept together here as a record of the foundational skills that later projects (see retail-sales-eda, house-price-prediction, customer-churn-classification) build on.

Topics Covered
Control flow & loops — conditionals, for/while loops, nested loops
Data structures — lists, dictionaries, sorting and filtering
Exception handling — try/except/finally, custom validation, file I/O error handling
Object-oriented programming — classes, __init__, instance methods, class vs. instance attributes
Applied mini-programs — console-based CRUD apps (student records, employee records, inventory management) combining OOP, dictionaries, and exception handling
Basic chatbot logic — keyword-matching intent detection with simple sentiment fallback (TextBlob)
Why This Repo Exists

Every analytics project starts with fluency in the basics. This repo isn't meant to showcase analysis — it's the groundwork: clean control flow, reliable error handling, and OOP structure, all of which show up applied in my analysis projects.

Files

Exercises are grouped by course day/assignment rather than by topic, reflecting how they were originally completed.
